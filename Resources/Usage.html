GO Tone Bridge

Use JUNO-DS Tone Manager with an original GO:KEYS or GO:PIANO.

  1. Connect the keyboard by USB or Bluetooth and select its MIDI input/output.
  2. Enable Allow writes for editing, Preview or Librarian Write. Leave it off for read-only access.
  3. Click Start. Wait for Ready, then open Tone Manager.
  4. In Tone Manager's System tab, select JUNO-DS GO Bridge for both input and output.
  5. Open Editor → Performance → Read. A part's Edit button opens its patch parameters.

Patches and performances

The Editor reads the current temporary sound. The Librarian reads stored user memory: choose a mode, select rows and click Read. Initial INIT rows are local defaults.

Use Tone Manager's Load/Import functions for third-party files. With Allow writes enabled, select rows to Preview or Write. Preview uses temporary memory. Write replaces selected stored slots, including whole banks. Back up stored data before replacing it and read destination rows back to check a transfer.

Catalogues

User names are read from all 128 performance, 256 patch and 8 drum-kit slots. Factory choosers use bundled lists of 59 performances and 1,377 patch/drum selections per model. Missing name reads are reported. Addresses and wave numbers are unchanged. Samples, multisamples and expansion storage are unsupported.

Logging

Record MIDI log is optional. Each connection gets a separate file under ~/Library/Logs/GO Tone Bridge/; existing logs are preserved. Show log opens the file location. No network access or telemetry is used.

Connection

Stop before changing options or reconnecting the keyboard. If no keyboard is listed, connect it in macOS Audio MIDI Setup or by USB, then click Refresh devices. Check both selected ports if identity checking times out. Start the bridge before selecting its ports in Tone Manager. Use one bridge and one Roland application at a time.
